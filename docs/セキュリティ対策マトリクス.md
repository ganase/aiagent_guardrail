# セキュリティ対策マトリクス

| リスクID | リスク | 初期動作 | 対象 | テスト |
|---|---|---|---|---|
| R01 | ブラックボックス化 | warn | README、AGENTS、CLAUDE、運用設計 | TC018, TC019 |
| R02 | 共有ワークスペース外への保存 | warn | Agent指示、利用者確認 | TC018 |
| R03 | bypass / auto approval | block | policy、Hook | TC001, TC002 |
| R04 | 破壊的コマンド | block | policy、Hook | TC003-TC006 |
| R05 | Secret / 認証情報読取 | block | policy、Hook | TC007-TC010 |
| R06 | 認証情報の外部送信 | block | Hook、JSONL | TC021 |
| R07 | 外部取得内容の即実行 | block | policy、Hook | TC011-TC013 |
| R08 | プロンプトインジェクション | warn | AGENTS、CLAUDE、利用者確認 | TC020 |
| R09 | 未知パッケージ利用 | allow / log | allowlist、Hook | 既存テスト |
| R10 | ランタイム・システム変更 | block | runtime policy、Hook | TC014-TC017 |

未知パッケージと軽微な外部取得は利用を一律停止せず、記録と確認を中心に扱う。Codexの直接実行などHook外の経路は本テンプレート単体では完全に強制できない。
