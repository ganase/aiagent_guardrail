AI Agent Workspace

システム構成図

1台のPCにインストールされたプログラム、Claude Code / Codex のローカルモジュール、作業リポジトリの置き場所、LLM（推論の実体）がどこにあるかを1枚で示します。ガードレール（審査・ブロックの仕組み）は対象外です。ガードレールの詳細は別紙 docs/ガードレール_システム構成図.html を参照してください。

対象読者: 導入担当者・利用者 関連文書: README.md、docs/user/導入手順書.md、docs/user/コード管理ルール.md

全体構成

ポイントは「実体がどこにあるか」です。プログラム・設定・履歴はローカルPCに、作業リポジトリは共有ワークスペース（Box等のネットワークドライブ）に、LLMそのものは社外のネットワークの先にあります。ローカルPCには、モデルの重みも作業リポジトリの正本も置きません。

利用プログラム（ランタイム） AIエージェント本体・ローカルモジュール 共有ワークスペース（リポジトリの位置） LLM（社外・ネットワーク越し）

要素の対応表

図中の各要素が、実際にはどのファイル・フォルダ・サービスを指すかの一覧です。

ローカルPC

ランタイムPython、Node.js、Git for Windows
AIエージェント本体claude、codex（CLI）
Claude Codeのモジュール~/.claude/（settings.json 等）
Codexのモジュール~/.codex/（config.toml 等）
導入フォルダC:\Users\<user>\AIAgent_Workspace\

共有ワークスペース

チーム共有リポジトリ<Box>\Operation\<repository>
個人用リポジトリ<Box>\Sandbox\<user>\<repository>
操作ログの同期先<Box>\Sandbox\<user>\AI-Agent-Audit\
部内業務利用（Level 3）時組織指定のGit基盤へも保存

LLM

API直接指定Anthropic API／OpenAI互換API
Gateway形式組織指定の認証サービス経由
モデルの重みローカルには存在しない（すべて外部）
この図に含まれないもの 危険コマンド・パッケージ導入の審査、機密ファイルアクセスのブロック、改ざん検知といった「ガードレール」の仕組みは、この図では意図的に省略しています。ガードレールがどのプログラム・設定に対して働くかは、別紙 docs/ガードレール_システム構成図.html を参照してください。
